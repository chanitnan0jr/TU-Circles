# TU Circles — Project Context

## Overview
TU Circles is a campus platform for Thammasat University students and staff aimed at building trusted communities, finding study partners, and discovering campus open calls.

## MVP Modules
1. **Identity Verification (TU API Integration)**
   - Authenticate TU students and staff against official TU Rest API.
   - Restrict features based on verified student/employee status.

2. **Study Buddy Matching**
   - Match students based on study interest tags and availability slots.

3. **Open Call Board**
   - Community board for team recruitment, activity calls, and project posts with filtering.

4. **LINE LIFF Distribution**
   - Mini App user interface running inside LINE LIFF.

## Phase 2 Features (Post-MVP)
- Attendance Integrity & Verified Badges
- Private Matching & AI Team Assistant
- Gamification & Reward Systems

*Note: Phase 2 development must not begin until all 4 MVP modules pass integration tests.*
